`mixed.xpt` is a synthetic SAS XPORT V5 fixture created for the Pandas reader tests.
It contains a numeric column, a Latin-1 character column, a SAS date column (days
since 1960-01-01), and a SAS datetime column (seconds since 1960-01-01). Three rows
cover positive and negative numbers, fractional seconds, accented text, and SAS
missing numeric values. It contains no real-world data.
